## 范围与展示规则

现有界面为中文，部分日期却使用系统语言；记餐日期控件另有`zh_Hans_CN`单点覆盖。既有UI测试强制中文启动，不能证明英文手机环境一致。本片仅统一日期时间展示，不新增语言切换、完整英文界面、日确认、日历或其他业务。

- 集中App层日期展示上下文，当前界面语言为简体中文，接受未来界面语言参数。保留手机地区、明确12／24小时制、当地时区及系统餐食日历偏好。英语显示名和Bundle设置保持。
- 只在日期文本和日期选择器使用该上下文，不全局替换数字locale，不改变小数解析、金额／营养数字、输入草稿或保存请求。
- 今日显示完整日期；今日餐食摘要仅时间；历史餐食显示日期＋分钟，跨年补年份；餐食详情显示完整日期＋分钟。目标列表确认时间保留分钟，版本详情保留秒。
- 目标生效日期继续按Gregorian民用`GoalDay.key`展示，同年省年份、跨年或无参考日保留年份。不得从`effectiveFrom`或当前时区重新推导。确认时间与餐食时间是时间点，按手机当地时区显示，保存的审计时区保持原值。
- 两个原生日期选择器使用统一语言和时区；目标选择器与表单当前持有的民用日期时区一致。保留既有前台时区刷新：保持所选民用日，更新表单时区并作废重试请求。展示上下文更新不重置View身份或表单基线。
- 无效旧时间保留中性不可用语义，不生成伪造日期。无已知历史的目标仍显示未知。

保留SwiftUI、Swift6、SwiftData、FoodDecisionCore及现有工程。SwiftData结构、V1/V2、唯一约束、存储、备份、保存命令、目标选版及Bundle ID `com.ning6y6.ShiHeng`不变，无新依赖。原9份未提交文件按差异及哈希保留，不混入本片。
