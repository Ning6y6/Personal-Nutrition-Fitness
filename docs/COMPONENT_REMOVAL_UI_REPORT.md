# 餐食与模板分项移除：界面小修

日期：2026-10-20（Europe/London）。基线：`d66d435`。分支：`fix/component-removal-actions`。

用户已确认 OPT-14A 真机验收通过，并批准本片界面小修及补充要求。OPT-13 个人食物卡仍未开始。

## 已实施范围

- 餐食／模板移除分项表头的“编辑／完成”及 EditMode 切换，不再因进入删除模式让整个输入区缩进。保留两行食物／重量布局、来源说明、自然高度和稳定分项 UUID。
- “添加食物”改为纯文字按钮，与食物标签左对齐；删除未使用的编辑表头组件及工程引用。
- 左滑使用系统 `swipeActions`，文字“移除”、破坏性角色及显式红色，保留全滑；长按仅作用于食物名称按钮，菜单为“移除此项”，重量框继续使用系统文字选择／粘贴。
- 选择页以固定原生 bottomBar 提供“从本餐移除”／“从模板移除”，替换“清空当前选择”。空白分项、失效来源、搜索无结果时也适用。工具栏按钮保持稳定身份；搜索聚焦时隐藏工具栏、将按钮设为透明／禁用／不接收触摸并从辅助功能树隐藏。用原生键盘“搜索”提交收起键盘，保留查询，不让破坏性按钮跟随键盘升起。
- 三个入口均按捕获的 UUID 定位，先清输入焦点，只改当前草稿。选择页先退出当前导航，父表单重新出现后消费待移除 ID；路由保留所选食品 ID 的值，过渡期不依赖将被移除的行，不闪出失效分项页面。
- 保存、取消／继续编辑／放弃、空白新稿语义和 OPT-14A 快照保存命令保持。没有结构／备份迁移，没有新依赖、云或账号；Bundle ID 保持 `com.ning6y6.ShiHeng`。原始工作区 10 个未提交文件独立保留，不纳入本片提交。

## 真机验收流程

覆盖安装新版，保留现有真机数据。使用唯一命名的自建验收餐／模板；建议米饭 100 g（当前内置“熟长粒白米饭（无盐）”为 131 kcal），另加同名 200 g 分项，用重量辨认两条。

1. **布局与文案：**餐食、模板都没有分项“编辑／完成”；“添加食物”为纯文字，与“食物”标签左对齐。食物名、重量和来源布局保留，整个分项区不再因切换模式横移；左滑时目标行随手势移动属于正常反馈。
2. **左滑／全滑：**只滑 200 g 那一条，显示红色“移除”；点它后 100 g 行和输入原文保持。重新添加样本，再全滑移除，检查同一规则，不误删相邻项。
3. **长按与重量焦点：**长按食物名称，出现“移除此项”。重量框长按仍能定位光标／选择／粘贴；对重量输入中的行执行移除后键盘收起。餐食与模板都检查。
4. **选择页与键盘：**点目标行“食物”，底部显示“从本餐移除”或“从模板移除”。点搜索框／输入无结果文本，键盘出现时移除按钮不可见；点键盘“搜索”收起后重新出现，查询及无结果状态保留。移除返回父表单，只消失打开选择页的那条。空白分项同样可移除；没有“清空当前选择”。
5. **返回与食品资料：**选择页进入食品资料后返回，仍定位原分项，草稿保持；移除时不闪出“分项已移除”页面，不跳到另一条同名食物。
6. **新稿与已有记录保护：**全新空白餐／模板，给初始行填重量再移除整行，名称未改时取消直接退出；改过名称仍须确认。已保存餐／模板移除全部行后不能保存，取消仍可继续编辑／明确放弃；放弃后原记录、重量与营养完整保留。
7. **保存与重开：**多项验收餐移除一项后保存，重开只保留剩余项，营养合计正确；再仅改餐名／时间，原营养保持。模板保存／重开及未保存放弃分别检查。
8. **辅助功能：**深色、大字号下操作可读可达；VoiceOver 逐项检查有明确“移除”动作且作用于正确分项、不出现混淆的重复动作。模拟器截图／AX 树不能代替真机 VoiceOver 转子操作验收。

任一出现即不通过：键盘旁出现可点的移除按钮；错删邻项；移除后残留失效焦点；放弃修改损坏原记录；原营养被当前食品重算；行 ID 或原始输入意外改变；移除入口不可发现或辅助功能不可用。
