## 真机验收

覆盖安装本片新版，不卸载、不清库。取消类检查不需要保存测试记录；最终删除只针对明确自建样本。

1. 今日→记录一餐→空白记录；不改名称、时间、记录选项。在唯一初始栏只输入重量100，不选择食物；点食物分项“编辑”并删除整条栏。此时没有分项、保存不可用。点顶部取消，应直接退出，不出现放弃提示，今日记录与合计不变。
2. 重开同一入口，分别用重量0、`.`检查“输入后删除整条栏→取消”。没有剩余分项、其他字段未改时都应直接退出；这不表示仍留在栏中的0或`.`可以保存。再重复一次删栏后下拉关闭，应能直接退出。
3. 新建空白记录先改餐食名称（或时间），输入重量后删除整条栏，再取消。必须仍提示放弃；继续编辑应保留修改及零分项，保存仍不可用；明确放弃后没有新餐食。
4. 新建空白记录只输入100或`.`，保留整条食物栏再取消。必须提示，继续编辑保留原文；这项保证仍存在的输入不会被当空白丢掉。
5. 记录一餐→管理常用模板→新建，重复第1–4项适用操作。未改名称且全部分项删光可直接退出，改名称或保留输入仍受保护，不产生空模板。
6. 打开已有餐食或已有模板编辑，试删原有分项后取消。必须仍受保护；选择继续编辑保留试删状态，再取消→放弃，重开必须保留原已保存食品及重量。复用／模板带入新餐也保持放弃保护。只取消／放弃，不按保存提交试删。
7. 检查外观、键盘完成、原生编辑控件及删除确认框保持原样；用大字号／深色重复新规则关键操作。现有真实记录保持，真机或VoiceOver问题单独记下复现步骤。

出现有剩余输入却直接丢弃、已有记录试删后直接关闭不提示、零行可保存或取消改变已保存数据，均判本片不通过。
