# 每日预算与目标表单简化计划

批准日期：2026-10-11。分支：`feat/goal-form-simplification`。基线：`6a0b270`。

本片减少目标编辑中的重复确认和默认展开控件。目标历史已经交付，本片保留其追加保存、默认明天、今天整日、同日最后确认、未来安排保留和未知过去的规则。

## 已确认交互

- 六个数字继续精确载入，首次不填示例；必填校验不变，可选留空表示未设置，明确0仍为0。
- 移除确认开关，按钮统一叫“保存”。点击保存承担主动确认，编辑草稿不自动确认；Core仍拒绝未确认的保存请求。这是对DECISIONS 013确认交互的补充，不撤销确认与事务保护要求。
- 生效日期始终提供今天、明天、其他日期，默认明天；其他日期在同一表单展开原生日历。准确的中文生效日期持续可见，跨年显示年份。选择今天说明用于今天整日。
- “目标依据”默认收起，显示自行选择或参考已有建议；保留明确来源分类，不按说明是否有文字推断。参考建议缺少说明时展开并提示“需填写说明”，收起后提示仍可见。
- 旧目标使用白话说明；有未来新版本时显示“新目标将于10月12日生效，今天仍使用当前目标”，今天无目标则明确说明。仅改提示，不让未来目标提前生效。
- 只展开或收起日期、依据不算数据编辑。实际修改后取消仍提供继续编辑和放弃修改，失败保留输入。

## 保存保护

每次数值、日期、来源、说明、时区或小数分隔符改变，作废缓存请求；保存入口再次同步比较当前完整输入和原请求，不依赖SwiftUI回调的先后。未改变内容的失败重试保留原操作ID、确认时间和基线；修改后生成新请求。

时区变化先刷新展示并要求核对，不在同一次点击自动按新时区提交。跨午夜保留实际选定日期；过期时阻止保存，不把日期静默推到未来。保存命令、独立关闭autosave的上下文、陈旧基线拒绝和幂等判断均保留。

## 边界和验收

本片不改Core选版、SwiftData V1/V2结构、迁移、备份格式、设置首页、餐食计算、Bundle ID或本地唯一约束；不处理今日页其他布局与热量格式问题。原七个修改文件和扫描规划原样保留，不混入本片。

自动化包含Core全量、全部App单元测试、相关真实XCTest模拟器交互和`./scripts/build-ios.sh`。重点验证请求变化/重试、文件库保存失败后更新、中文跨年日期、旧目标和未来提示优先级、真实日期选择、来源说明校验、取消及nil/0往返。最大辅助字号实际设置后运行相关交互，再恢复原字号。

真机验收只使用本人实际目标，先私下导出全量备份。测试数值和UI注释仅写入合成QA模拟器；不卸载、清库或打开未知用户数据库。模拟器通过不代替真机、跨午夜、时区和VoiceOver证据。实际结果另记交付报告。
