# 历史餐食详情、编辑、删除与今日汇总重算计划

更新日期：2026-10-04

## 目标

完成路线图 P0 的第一个开发切片，让已保存餐食可以被查看、修正和删除，并确保任何修改立即反映到今日营养汇总。

## 严格范围

本切片只实现：

1. 从今日记录进入餐食详情。
2. 从首页进入全部历史餐食列表，并查看任意餐食详情。
3. 使用现有录入表单编辑餐食名称、时间、记录方式、覆盖状态、食物分项和重量。
4. 删除餐食前显示二次确认。
5. 编辑或删除后，今日餐数和营养合计由 SwiftData 查询立即重算。
6. 为更新、级联删除和汇总重算增加自动化测试。

本切片不实现：常用菜模板、自定义食物、拍照识别、真实 AI、食品标签扫描、HealthKit、CloudKit、营养目标算法或首页视觉重做。

## 实施顺序

1. 为 `PersistentMealLog` 增加可测试的原子更新方法，明确替换分项并删除旧分项。
2. 将 `MealEntryView` 扩展为新建/编辑双模式；取消编辑不得改变原记录。
3. 增加历史列表和详情页；详情页提供编辑与带确认的删除操作。
4. 将首页今日记录变为可点击入口，并增加全部历史入口。
5. 运行 SwiftData 更新、级联删除和今日重算测试。
6. 运行核心包测试、iOS 单元测试与 App 构建，最后更新执行状态和路线图。

## 验收标准

- 点击首页中的今日餐食可以看到完整详情。
- 可以从首页查看不属于今天的历史餐食。
- 编辑保存后，详情、历史列表和首页今日汇总显示新值。
- 将餐食时间从今天改到其他日期后，该餐自动移出今日汇总。
- 删除必须二次确认；确认后餐食及其分项均从 SwiftData 删除。
- 删除今日餐食后，今日餐数和六项营养合计立即减少。
- 取消编辑不会写入任何变更。
- 所有新增测试、原有核心测试和 iOS App 构建通过。
