### 键盘布局警告的边界

R2 / R3 的两条警告都落在目标表单首次点击输入框、键盘弹出的瞬间，在 `typeText` 前；R3 activity 标记 `isAssociatedWithFailure=false`。此时今日为中性空态，没有渲染热量环；目标表单无 `.frame` / `GeometryReader`。xcresult 调用栈没有符号或源码位置，不能据此断言是系统 bug，也不能随意修改营养数值或添加 frame 钳位。

后续 UI-2B 原生大尺寸 sheet / 键盘工具栏验收需要再次观察，并可将同目标表单在有 / 无 Tab 外壳下做隔离比较。运行时警告单独挂账，自动化成功不等于零警告、VoiceOver 或真机键盘体验已经通过。

## UI-2C：餐食轻量就地展开

状态：`feat/inline-meal-details`代码与适用功能门禁已通过，本片独立交付；UI-2B已以`2b18a34`独立提交并推送任务分支 / main后才开始本片。提交与远端状态以Git记录为准；未定位布局警告、真机专项与 iOS 26 运行时仍挂账。

### 实现与不变项

- 今日和历史使用同一 `MealExpandableRow`。每个列表只保留一个瞬时展开 ID；再次点选收起、选另一餐替换，删除、移出可见列表或日期窗口改变后清除失效状态，不把展开状态写入数据库。
- 展开只读已保存的食物名称、重量与营养快照，不用当前食品库重算旧餐。证据 D 与异常记录明确标记原始快照、不可复用；未知纤维和明确 0 保持区分，不安全数值显示“不可用”。
- 编辑、复用和查看详情均有可见的至少 44pt 原生按钮，不依赖隐藏手势。编辑 / 复用仍进入原表单，详情保留原删除确认和存模板流程；营养规则、十二实体 V1、唯一约束、保存 / 恢复事务和 Bundle ID 均不变。
- 展开采用系统默认动画，减少动态效果时不执行动画；辅助字号垂直排列、完整换行和自然高度，没有移植网页曲线、固定高度或分段延时。实际 VoiceOver 和减少动态效果专项尚未执行。
