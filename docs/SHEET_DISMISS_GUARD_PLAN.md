## 行为契约

1. 初始化后的默认值、已保存值、历史/模板复用预填值作为本次编辑基线；仅打开表单不算修改。
2. 餐名/模板名、时间、记录方式、覆盖状态、目标字段/确认开关、食物与原始重量文字、分项增删或顺序改变均参与比较。焦点、键盘“完成”和高级项展开不算修改。
3. 当前草稿与基线不同：禁用下拉关闭；点“取消”显示“继续编辑 / 放弃修改”。继续编辑保留全部输入，放弃修改才退出，不执行保存或数据库回滚。
4. 当前草稿等于基线：允许下拉关闭或直接取消。改回原来的字段内容后恢复该行为。
5. 未填完、非法重量文字、目标留空与明确 0 也参与保护；不能以“可以保存”为判断条件。重量原始文字仅存在 App 表单内，计算/保存边界转换为现有 Core 草稿。
6. 预填重量保留 Double 往返精度；非法旧重量以稳定原始文字显示，不因 NaN 自身不相等而误报修改。保存失败及错误提示关闭不重置基线。
7. 显式保存成功仍直接退出；保护不阻断成功保存，也不改变现有餐食/目标/模板事务或模板计数。
8. 本次验收中的 iOS 27 原生 popover 会省略 `role: .cancel` 操作，因此“继续编辑”使用显式普通按钮，保证与“放弃修改”两个出口都可见；点外部关闭确认弹窗也只继续编辑，不丢弃草稿。
