# 温和精确：交互与动效规范 02

范围：用户于 2026-10-07 提出的交互方案，先在本地 Flask 沙盒试用。此规范不是正式 iOS 导航、美化、日级统计或语言模块的实施批准。真实记录、数据库、Schema、健康规则及原阶段门禁不变。

## 取舍

- 采用「今日 / 扫描 / 趋势 / 设置」。趋势包含七日图与月历；原生 App 的正式名称与页面映射仍待确认。
- 采用右下角悬浮记录入口，直接进入记录表单，减少一层选择。沿用草稿取消确认，不因动效取消保护。
- 餐食行在原列表中展开，不弹详情层，不跳页；同一时刻展开一项。
- 今日热量预算移到滚动内容以外的固定顶部栏；快速编辑只改演示热量，完整营养目标仍在设置中。
- streak 只计「连续有餐食记录的日期」，不是完整日证明、不是连续达标，更不奖励低热量或少吃。今天尚未记录时，明确显示截至昨天。
- 语言提供中文与英文；用户输入的餐名不自动翻译。

## 统一 token

| 项目 | 规范 | 用途 |
| --- | --- | --- |
| 几何曲线 | `cubic-bezier(.22,1,.36,1)` | 形变、列表高度、导航选中背景与数字滚动 |
| 主时长 | 480 ms | 展开 / 收回，页面轻微淡入与数字滚动 |
| 交错步长 | 4 个 60 Hz 设计帧，约 66.7 ms | 不是随真实屏幕刷新率变化的帧计数 |
| 辅助淡入 | CSS 统一 reveal token | 容器落定后才揭示内容 |
| 减少动态效果 | 去位移、尺寸动画与滚动计数，仅短淡入 / 即时结果 | 同时尊重系统与预览内开关 |
| 材质 | 玻璃近似只用于导航、顶部预算按钮与悬浮控件 | 营养数字、表单与详情保持不透明 |

`static/motion.js` 管理 JS 几何 / 数字 token，`static/style.css` 管理 CSS token。语义不由动画决定；颜色始终配文字。SwiftUI Pro 的设计、视图、性能与无障碍参考约束本次原型：共享规格、结构身份、减少动态效果、对比度、控件标签，以及避免将数字放在玻璃材质上。

## 形变与列表契约

`#record-morph` 是一直存在的同一 DOM 容器：58 px 悬浮入口 → 按内容测量的面板。先执行容器形变，等待动画完成，再按顺序显示内容；容器未落定时输入不可交互。面板高度受手机可用空间限制，过长内容在面板内部滚动。

关闭使用同一帧对、同一曲线的反向播放。如果途中关闭，从当前视觉矩形收回，不能瞬间跳到完整面板。保存成功才退出；未保存输入，包括 `number` 字段的 `badInput` 临时文字，取消或点击背景均需确认。

餐食详情真实动画高度，后续列表项随布局一起移动。高度落定后，示意图 → 文字 → 标签三阶段揭示。收回反向播放；收回途中再次展开，从当前高度继续。详情图是代码绘制的示意图，不是用户餐食照片。

## 七日趋势

- 以演示日期 2026-10-07 为锚点，绘制最近七个日历日，不依赖浏览器当前时钟；仅虚构数据。
- 缺失值保留 `null`，不补 0，不跨缺口连线；真正的 0 记录保留为 0。
- 横向日期带使用 `scroll-snap`；按实际元素中心确定吸附日期。可点日期、左右滑动、在图上拖动，或用方向键 / Home / End。
- 顶部计数器只在两个有效数值之间滚动；缺失日直接显示「— / 无记录」。
- 七日范围内，选择日历日期同步图表；范围外的月历日期不伪造七日数据，图表保留独立明确日期。
- 连续记录以至少一餐为条件，不等同于日级覆盖确认或真实营养趋势分析。

## 本地与后续落地

配色导入 / 导出继续采用严格设计 JSON v1，契约未改变。语言、减少动效与透明度偏好独立存于浏览器；不会写进设计 JSON，也不会导出餐食数据。刷新重置模拟餐食与目标，保留设计和偏好。

网页玻璃由 CSS 近似实现，不称为 Apple 原生 Liquid Glass。未来批准原生切片时，导航用系统 `TabView`，可融合控件采用 `GlassEffectContainer` / 原生玻璃 API；保持系统安全区、Dynamic Type、VoiceOver 和减少动态效果验收，不能照搬网页像素尺寸。

参考：[Apple 自定义 Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。无需安装动画库、React Native 或其他 iOS 依赖。

## 验证边界

后端与纯前端测试分别运行；浏览器实际验证不冒充 iOS 模拟器、真机、VoiceOver 或性能验收。当前网页仅用于确定配色、布局和动作手感。正式四栏导航、完整日历、扫描、日级确认与现有页面全面视觉改版仍未完成。
